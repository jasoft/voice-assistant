# 隐患与关注点 (CONCERNS.md)

## 技术隐患
- **工具依赖**: 日志系统高度依赖系统安装了 `jq` 命令，若缺少此依赖，JSON 格式化将退化为纯文本。
- **音频兼容性**: `sounddevice` 在不同操作系统的音频驱动（Core Audio, ALSA 等）下表现可能不一，尤其是录音键释放的响应延迟。
- **双引擎存储**: 目前支持 SQLite FTS5 和 PocketBase/Mem0，多后端的数据一致性和迁移逻辑（如同步本地历史到云端）需重点关注。

## 业务关注点
- **提示词维护**: `workflow_config.json` 变得非常庞大，随着意图分类增加，提示词的回归测试成本会上升。
- **图片处理**: 图片记录逻辑（`photo_path`）目前为强制 `record` 意图，未来可能需要更细致的视觉语义分析。

## 环境建议
- **CI/CD**: 由于包含大量涉及模型 API 的 E2E 测试，建议在 CI 流程中严格管理 API Key 的配额和安全性。
